# Erin Spencer

Independent systems researcher and builder of [The Interdependency](https://github.com/The-Interdependency).

I build executable research systems around agent architecture, formal geometry,
measurement, provenance, metadata, language representation, and mobile-first AI
infrastructure. Work is developed through explicit assumptions, falsification,
reproducible evidence, and preserved uncertainty.

## Start here

The canonical current work lives in **[The-Interdependency](https://github.com/The-Interdependency)**.
Repository READMEs carry each project's present scope, authority, evidence status,
limitations, and verification guidance.

Selected active work:

- **[a0](https://github.com/The-Interdependency/a0)** — public-facing research instrument for persistent-agent architecture and multi-model orchestration.
- **[skill-lib](https://github.com/The-Interdependency/skill-lib)** — portable agent skills and MSDMD native-first metadata tooling.

- **[UCNS](https://github.com/The-Interdependency/ucns)** — exact geometric constructions including Public Gonol carriers and framed Möbius motion.
- **[EDCM](https://github.com/The-Interdependency/edcm)** — measurement and evaluation research with provenance-preserving result contracts.
- **[EPAC](https://github.com/The-Interdependency/epac)** — elementary/particle-scale energy-and-arity coupling research with explicit falsification boundaries.
- **[METAPAT](https://github.com/The-Interdependency/metapat)** — semantic authority for cross-domain structural comparison and constrained terminology transfer.
- **[UCHC](https://github.com/The-Interdependency/uchc)** — Unit Circle Hyperspace Constructs for human and programming-language representations; current release status is documented in-repo.

## Working method

I use multiple AI systems as computational and critical tools. No model is treated
as authoritative. Claims are separated from evidence, negative results are retained,
and unresolved constraints remain explicit rather than being silently completed.

## Using this work

Start with the README of the repository you intend to use. Check its license,
current status, verification instructions, and stated nonclaims before treating an
implementation as established theory, validated measurement, secure infrastructure,
or a production dependency.

Historical personal repositories remain visible for provenance. Current canonical
development should be read from the organization repositories above.
